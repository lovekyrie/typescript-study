# Learning Journal: 2026-05-19

## Q1: ts-loader 在打包里做什么？和 Babel 一样吗？

**Context**: `ts-base` Webpack 配置、`docs/webpack打包与转译.md`

**Key points**:

- Webpack 负责打包；ts-loader 只负责把 `.ts` 转成 JS 模块（底层是 tsc，不是 Babel）。
- 本仓库 `transpileOnly: true`：打包只转译，类型检查用 `npm run type-check`。
- Babel 也能转译（见 `ts-babel/`），但不查类型；两边都可采用「转译 + 单独 tsc」分工。
- `noEmit: true` 限制 CLI 写盘，不阻止 ts-loader 在内存里 emit。

**Details**: [../knowledge/tooling/webpack-transpile.md](../knowledge/tooling/webpack-transpile.md)

# Learning Journal: 2026-06-26

## Q1: TypeScript 7 RC 中 tsc、tsgo 和 ts-loader 怎么迁移？

**Context**: `README.md`、`docs/knowledge/tooling/webpack-transpile.md`、`ts-base/package.json`、`ts-babel/package.json`

**Key points**:

- `typescript@7.0.1-rc` 的 npm 包入口命令仍是 `tsc`，但它会调用当前平台的 Go 原生编译器二进制。
- `tsgo` 主要对应 `@typescript/native-preview` 预览/夜间包语境；本仓库当前精确锁定的是 `typescript@7.0.1-rc`。
- `ts-loader` 依赖经典 TypeScript JS API，暂不适合直接接入 TS 7 RC 原生包。
- 当前仓库保留 `npm run type-check` 调用 TS 7 RC 原生编译器，Webpack 打包转译继续走 Babel。

**Details**: [../knowledge/tooling/webpack-transpile.md](../knowledge/tooling/webpack-transpile.md)
